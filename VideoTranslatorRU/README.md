# Chinese → Russian LIVE v0.2.0

Android-приложение для живого перевода китайской речи и текста с экрана на русский.

## Что умеет
- Китайская речь → русские субтитры поверх видео/стрима.
- Захват системного аудио через AudioPlaybackCapture.
- Запасной режим через микрофон.
- OCR китайского текста на экране через ML Kit.
- Перевод Chinese → Russian через ML Kit Translate.
- Локальное распознавание китайской речи через Vosk.
- Настройка размера субтитров и прозрачности.
- Отдельные компактные карточки: OCR сверху, речь снизу.

## v0.2.0
- Исправлен критический баг MediaProjection: `Activity.RESULT_OK` равен `-1`, а v0.1 ошибочно принимала это значение за отсутствие разрешения.
- Доступ к экрану теперь выдаётся отдельным шагом перед запуском.
- Полностью переделан главный интерфейс.
- Добавлены статусы разрешений и понятные сообщения об ошибках.
- Переделан overlay субтитров без полноэкранного пустого слоя.
- Добавлены автоскрытие, размеры, прозрачность и показ оригинального китайского.
- Добавлена подсказка, если внутренний звук не поступает.

## Важно
На Android 14+ разрешение MediaProjection требуется получать заново перед новым сеансом захвата. Некоторые приложения запрещают захват внутреннего аудио; в таком случае используйте режим «Микрофон».
