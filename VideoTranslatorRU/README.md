# Китайский → Русский LIVE (Android)

Прототип Android-приложения для перевода китайской речи и китайского текста на экране в русский язык в реальном времени.

## Что умеет
- Показывает русские субтитры поверх других приложений.
- Распознаёт китайскую речь локально через Vosk.
- Захватывает системный звук через Android AudioPlaybackCapture или использует микрофон как запасной режим.
- Распознаёт китайский текст на кадрах экрана через ML Kit Chinese OCR.
- Переводит китайский → русский через ML Kit on-device translation.
- Работает поверх видео, браузера и прямых эфиров после выдачи MediaProjection + overlay разрешений.

## Ограничение Android
Звук другого приложения можно захватывать только если оно разрешает `AudioPlaybackCapture`. Если источник блокирует захват, выберите режим «Микрофон».

## Первый запуск
Приложение загрузит модель Vosk `vosk-model-small-cn-0.22` (~42 МБ) и модель перевода ML Kit.

## Сборка
```bash
gradle :app:assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.
